# Resume Forge

把一份简历从「有素材」推到「能投出去的 PDF」。产出物固定为三件，缺一件都算没做完：

```text
我的简历-vX.Y.md     # 正文，唯一事实来源，先改这里
resume.html          # A4 打印模板，只换内容不动 CSS 结构
我的简历-vX.Y.pdf    # 成品，页数、留白、断页都已验过
```

**$SKILL_DIR** = 本 skill 的安装目录。常见位置：

| 场景 | 路径 |
|---|---|
| Claude Code（全局 / 项目） | `~/.claude/skills/resume-forge` · `.claude/skills/resume-forge` |
| Codex / Pi / Cursor / Freebuff / 通用 | `~/.agents/skills/resume-forge` · `.agents/skills/resume-forge` |
| 其他支持 Agent Skills 的工具 | 其 skills 目录下的 `resume-forge/` |

不确定就 `ls` 一下自己所在的目录，或 `npx skills list`。

## 铁律

违反任意一条，宁可停下来问用户，也不要自行补全。

1. **不编造。** 不新增项目、不新增业务模块、不造指标、不改头衔年限。原文没有的事实，一律写占位符交给用户补。
2. **口径要核实到「说出口不心虚」。** 头衔、年限、团队规模、公司性质（外包 / 驻场 / 甲方）都要和用户确认过。累计 Leader 年限按时间段相加，不能取整成「近 N 年」。
3. **指标只搬不改。** 原文「开发效率提升 25%」不能改写成「重复页面开发量下降 25%」——换个说法就换了事实。
4. **读者只有招聘方。** 平台专属文案（Boss 直聘「个人优势」粘贴版、期望薪资面议、投递备注）不许进简历；用户需要就另存一个 txt 给他。
5. **排版服务内容。** 不为凑满一页加废话，也不为压页删证据。宁可末页留白 30%，也不要把正文挤成 9pt。

## 流程

### Step 1 · 建立事实表（不写正文）

读用户给的所有材料（旧 PDF、md、聊天里口述的补充），列一张表：

| 字段 | 值 | 来源 | 冲突 / 待确认 |
|---|---|---|---|
| 总年限起算 | YYYY.MM | 旧 PDF / 用户口述 | 旧版写「N 年」，md 写「M 年」→ 以入职时间倒推 |
| Leader 累计 | 起–止 + 起–止 | 各段经历 | 用户说「近 N 年」，实际累加多少 |
| 公司性质 | 甲方 / 外包 / 驻场 | 用户口述 | 是否显式标注 |

冲突项必须在 Step 4 之前问清楚，或在正文里用中性写法消化掉。

### Step 2 · 审计

按 `references/rewrite-rules.md` 的禁止项与诚实口径走一遍，输出：一句话结论 + 3~6 个关键问题（每个说清「为什么会被刷 + 怎么改」）。不要边审边改，先让用户看到问题清单。

### Step 3 · 选模板

四套模板在 `assets/templates/<style>/index.html`，class 命名一致，可整套换也可只换 `--accent`。

| 模板 | 观感 | 默认页数 | 适合 |
|---|---|---|---|
| `classic` | 单栏 · 深松石绿 | 2 | 5~15 年技术岗，通用投递，最稳（默认选它） |
| `mono` | 黑白极简 · 无彩色 | 2 | 黑白打印、外企、设计感团队 |
| `navy` | 藏青页眉色块 · 双栏技能 | 2 | 大厂 / 管理岗 / 想让简历「重」一点 |
| `sidebar` | 左信息栏 · 双栏 | 1 | 3~8 年经验，一页交代完 |

用户没指定就选 `classic`，并在汇报里说明选了什么、为什么。改模板细节见 `references/template-guide.md`。

### Step 4 · 重写正文

按 `references/rewrite-rules.md` 的结构与句型重写，落到 md 文件。动笔前先定三件事：

- **页数**：12 年以上经验默认 2 页，5 年以下默认 1 页，用户指定则从其指定。
- **结构**：默认「概述 → 核心能力 → 核心项目 ×N → 工作经历 → 教育」。核心项目在前；工作经历只做时间轴与一句话职责，**不与项目重复指标**。
- **头衔口径**：完成时态的经历才写 Leader；在职的写实际岗位，Leader 年限在概述里一次性说清。

### Step 5 · 自审（最容易跳过，也最容易翻车）

把自己写的稿子当成别人的稿子，逐条挑：

1. 每个数字回到原文找得到出处吗？
2. 每个业务模块（原文没提的「商品 / 活动 / 配置」之类）真的存在吗？
3. 头衔、年限、团队人数有没有被悄悄放大？
4. 有没有两个地方其实在说同一件事（概述 vs 项目 vs 工作经历）？
5. 有没有自我评价式空话（「责任心强」「抗压」）？

发现编造，直接删，不要美化。这一步实际命中率很高，宁可多删。

### Step 6 · 装模板

```bash
cp "$SKILL_DIR/assets/templates/classic/index.html" resume.html
```

只替换 `<body>` 里的文字节点，保留全部 class 与 CSS。复制一整段 `<section>` 来增删区块，比手写安全。要点（细节见 `references/layout-spec.md`）：

- A4、`@page{ size:A4; margin:13mm 15mm 12mm }`，**单一流式容器，不写死 `.page` 分页**，让浏览器自然断页；
- `.item` 默认 `break-inside:auto`（页底不留白，代价是项目可能跨页），小节标题 `break-after:avoid` 防孤儿标题；
- 正文 9.5pt / 行高 1.68，数字 `font-variant-numeric:tabular-nums`；
- 单强调色（默认深松石 `#14655f`），层级靠字重与分隔细线；
- 占位符用 `.todo` 样式，导出前要么补数要么明确告知保留。

### Step 7 · 导出 PDF

```bash
bash "$SKILL_DIR/scripts/export_pdf.sh" resume.html "我的简历-v1.0.pdf"
```

脚本内置了 Windows 上的两个坑：Chrome `--print-to-pdf` 不接受中文输出路径、必须 `--no-pdf-header-footer`。macOS / Linux 手动导出时也要关掉页眉页脚并勾选「背景图形」。

### Step 8 · 验版（不跑这一步不算完成）

```bash
python "$SKILL_DIR/scripts/check_pdf.py" "我的简历-v1.0.pdf" --expect 2 --render
```

验收口径见 `references/verify-checklist.md`。硬指标：

| # | 检查 | 阈值 |
|---|---|---|
| 1 | 页数 | == 期望页数 |
| 2 | 第 1 页填充率 | ≥ 90%（单页 PDF 只看 ≥ 75%） |
| 3 | 末页填充率 | ≥ 60% |
| 4 | 页首无孤立区块标题 | 无 |
| 5 | 已删内容在 PDF 文本里确实不存在 | `--absent 关键词` |

失败时按 `references/layout-spec.md` 的「分页失衡排查顺序」调，**一次只改一个变量**，改完重新导出。

### Step 9 · 汇报

说清三件事：改了什么（尤其删掉了什么、为什么删）、怎么验的（页数与填充率的实际数字）、还有什么需要用户补（占位符清单、待确认口径）。

## 决策点（每次都显式告诉用户，不要默默选）

| 决策 | 默认 | 说明 |
|---|---|---|
| 页数 | 12 年以上 2 页 | 内容只有 1.7 页时不要注水到 2 页，也不要硬压到 1 页 |
| 模板 | `classic` | 用户没偏好就选最稳的一套 |
| 外包 / 驻场表述 | 中性写「公司（客户）｜岗位（驻场交付）」 | 不隐瞒也不放大，让用户自己定 |
| 个人项目 | 保留但标「个人项目 · 全栈独立开发」，放最后 | 无真实用户的玩具项目压到 3 条以内 |
| 占位符 | 保留并在末尾一次性列出 | 绝不代填 |
| 求职意向 | 单一方向 > 双方向 | 双方向会让面试官不知道该按哪个岗位定级 |

## 文件

| 路径 | 用途 |
|---|---|
| `assets/templates/{classic,mono,navy,sidebar}/index.html` | 四套 A4 模板，单文件无外部依赖，替换文字即可 |
| `scripts/export_pdf.sh` | Chrome headless 导出，处理中文路径与页眉页脚 |
| `scripts/check_pdf.py` | 页数 / 填充率 / 关键词 / PNG 预览 |
| `references/rewrite-rules.md` | 中文简历结构、句型库、禁止项、诚实口径、占位符规范 |
| `references/layout-spec.md` | 排版规格与分页调参手册 |
| `references/verify-checklist.md` | 导出验收清单与常见故障 |
| `references/template-guide.md` | 改内容 / 调密度 / 换配色 / 打印设置 / 故障排查 |

## 输出规范

- 简体中文；直接但不羞辱。
- 每个判断给简历里的证据（引用原句）。
- 缺失信息标占位符，绝不脑补。
- 只交成品文件 + 验版数字，不把过程稿堆给用户。
